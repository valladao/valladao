# 👋 Hi, I'm Manoel Valladão

Senior Shopify Developer focused on theme customization, technical troubleshooting, and performance.

I have been working in the market for more than 16 years, helping Shopify brands and teams ship reliable storefront work in production. My experience spans Shopify Liquid, Online Store 2.0, accessibility, analytics, performance optimization, and modern frontend tooling across long-term e-commerce operations and enterprise delivery.

## Recent Work

My most recent enterprise Shopify work includes Native Cos and Decathlon.

At BairesDev, I contributed to the Native Cos Shopify storefront under the P&G Beauty DTC ecosystem from build to go-live and post-launch iterations. The work included 70+ pull requests across PDP, cart, variant listing, image modules, subscription-related flows, mobile fixes, and iterative accessibility improvements.

Before that, I worked for Decathlon USA across long-term Shopify operations involving theme evolution, Online Store 2.0 direction, performance initiatives, accessibility implementation cycles, analytics modernization, and early Hydrogen setup work.
